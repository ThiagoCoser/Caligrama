# Gerador de Caligramas

Esta projeto foi realizada para a disciplina V204 - Laboratório IV, oferecida no instituto de Artes da Universidade Estadual de Campinas, no segundo semestre de 2026, com o nome, Impressões gráficas: considerações sobre o tempo e a memória na produção de livros de artista e livros-objetos, ministrada pela docente Luise Weiss com a professora convidada Fabiana Grassano.

# Atalhos

- W - Ativa webcam
- S - ativa som
- Q	- Diminui intensidade do efeito webcam (−0.5)
- E	- Aumenta intensidade do efeito webcam (+0.5)
- Z	- Diminui intensidade do efeito som (−0.5)
- X	- Aumenta intensidade do efeito som (+0.5)
- Esc - sai
